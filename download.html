Installation sequence

  1. Register: create your game account.
  2. Game files: new players download and extract the Core3 client ZIP. Existing players keep their current game folder.
  3. Launcher: close the game and launcher, download the complete EXE installer above and run it through the normal Windows installation prompts. Do not disable security software or install an old repair package.
  4. Open: launch the installed launcher and select your extracted Core3 game folder.
  5. Select server: choose SOM pre-cu.
  6. Update: run Scan/Update, wait for completion, then Play.

Current launcher: latest verified release. The download button always resolves the newest signed release. Existing installations offer launcher updates automatically; use Scan/Update for game patches. If an older launcher's self-updater fails, use the complete installer above. If Windows blocks it, preserve the exact message and ask for help rather than bypassing security warnings.
