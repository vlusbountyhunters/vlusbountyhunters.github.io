Installation sequence

  1. Register: create your secure game account.
  2. Download: wait for the Core3 and launcher ZIP files to finish completely.
  3. Extract: right-click each ZIP and choose Extract All. Do not run files from inside a ZIP.
  4. Open: run VLUCore3Launcher.exe from the extracted launcher folder and select your extracted Core3 folder.
  5. Shortcut: optionally run Create VLU Desktop Shortcut.cmd once.
  6. Play: use Scan / Repair, then Play VLU Core3.

The launcher is locked to VLU Core3 and rejects NGE or Aftermath patch entries.
