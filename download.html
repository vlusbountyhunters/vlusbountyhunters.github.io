Installation sequence

  1. Register: create your secure game account.
  2. Download: wait for the Core3 and launcher ZIP files to finish completely.
  3. Extract: right-click each ZIP and choose Extract All. Do not run files from inside a ZIP.
  4. Open: run VLUSWGLauncher.exe from the extracted launcher folder and select your extracted Core3 folder.
  5. Scan: allow the launcher to verify and update all files.
  6. Play: enter your account details and enter the galaxy.

Connection settings are managed automatically by the VLU launcher.
