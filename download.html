Installation sequence

  1. Register: create your secure game account.
  2. Download: wait for the Core3 client and launcher ZIP files to finish completely.
  3. Extract: right-click each ZIP and choose Extract All. Do not run files from inside a ZIP.
  4. Open: run SWGTalonLauncher.exe from the extracted launcher folder and point it at your extracted Core3 client folder.
  5. Select server: choose Vlu Pre-CU from the launcher’s server dropdown.
  6. Play: use Scan / Repair, then Play.

The SWG Talon Launcher is shared across Core3 and NGE — always confirm Vlu Pre-CU is selected in the dropdown before you play.
